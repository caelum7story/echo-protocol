# Security

This is public-beta source, not an independent audit. Do not infer safety or investment returns from source matching, a passing build or local tests. The Launch security findings and the public website risk page describe outstanding review limitations.

Report issues through the official ECHO channels linked at https://echobsc.fun/. Do not include private keys, recovery phrases, sessions, personal data or an executable exploit against live user funds in a public issue.

Build and local tests need no production keys. Never use deterministic fixture wallets outside isolated local tests. The reference test harnesses use synthetic accounts deliberately.
